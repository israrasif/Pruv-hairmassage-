# Hair Massage App

Expo + React Native + TypeScript app with 5 screens:

1. **Massage** (`app/(tabs)/index.tsx`) — video/GIF demo player, circular countdown timer, and toggle switches for technique preferences (Scalp Massage, Oil Treatment, Steam Therapy, Post-Wash Care). Completing a session logs it locally.
2. **Vault** (`app/(tabs)/vault.tsx`) — camera + photo library import, stored privately on-device (`FileSystem.documentDirectory`), grid view, tap to view/delete.
3. **Tracker** (`app/(tabs)/tracker.tsx`) — current/longest streak and a 30-day activity grid.
4. **Community** (`app/(tabs)/community.tsx`) — threads list + in-thread chat. **Currently local-only (mock data), see note below.**
5. **Analyze** (`app/(tabs)/analyze.tsx`) — weekly bar chart, a rough consistency score, and a plain-language insight message.

## Architecture notes

- **Local-first**: sessions, preferences, and vault photos persist via `@react-native-async-storage/async-storage` + `expo-file-system`, so the app is fully usable offline with zero backend.
- **Community is the one piece that needs a real backend** for actual multi-user chat (right now it's a local mock so you can see the UI/UX work end-to-end). When you're ready, swap `utils/storage.ts`'s thread functions for calls to Firebase Firestore, Supabase, or a custom API, and add auth (Firebase Auth / Clerk / Supabase Auth) so posts have real identities and moderation is possible. Happy to wire this up in a follow-up.
- The video in `components/MediaPlayer.tsx` points at a placeholder sample video — swap `DEFAULT_SOURCE` for your own hosted video/GIF, or bundle one locally with `require("../assets/technique.mp4")`.

## Getting started

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go (iOS/Android) for the fastest first look, or press `i` / `a` for simulators.

## Before you ship

- Replace `assets/icon.png`, `assets/splash.png`, and `assets/adaptive-icon.png` with real artwork (this scaffold doesn't include binary image assets).
- Update `app.json`: `ios.bundleIdentifier` and `android.package` to your real reverse-DNS identifiers, plus your final app name.
- Decide on the community backend (see above) before launch — a purely local community tab won't let users see each other's posts.

## Building & submitting with EAS

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build --platform ios
eas build --platform android
eas submit --platform ios
eas submit --platform android
```

You'll need:
- An Apple Developer account ($99/yr) and App Store Connect app record for iOS.
- A Google Play Console account ($25 one-time) and a Play Console app record for Android.
- `eas.json` (generated by `eas build:configure`) tuned for your build profiles (development/preview/production).
